# True Sleep Tool - MySystem

ابزار ویندوز 11 برای ورود واقعی لپ‌تاپ به حالت خواب و جلوگیری از حالتی که فقط نمایشگر خاموش می‌شود اما فن و CPU روشن می‌مانند.

## حالت‌ها

- **خواب عمیق:** از Hibernate استفاده می‌کند؛ برنامه‌ها و فایل‌های باز حفظ می‌شوند اما برق CPU و فن کاملاً قطع می‌شود.
- **Force Sleep:** فرمان Suspend استاندارد ویندوز را مستقیماً اجرا می‌کند.
- **تنظیم بستن در لپ‌تاپ:** با دسترسی Administrator، عملکرد بستن در لپ‌تاپ را روی خواب عمیق قرار می‌دهد؛ هم برای باتری و هم هنگام اتصال به برق.

## نصب

1. از بخش **Releases** فایل `TrueSleep-win-x64.zip` را دانلود کنید. برای دستگاه‌های ARM فایل `win-arm64` را بگیرید.
2. فایل ZIP را Extract کنید.
3. `TrueSleep.exe` را اجرا کنید.
4. برای خاموش‌شدن قطعی فن و CPU، گزینهٔ **خواب عمیق** را بزنید.

برنامه Self-contained است و به نصب .NET نیاز ندارد.

## نکته

در لپ‌تاپ‌های دارای Modern Standby، ویندوز ممکن است در Sleep استاندارد همچنان بخشی از سخت‌افزار را فعال نگه دارد. نرم‌افزار نمی‌تواند حالت S3 را به Firmware دستگاهی که از آن پشتیبانی نمی‌کند اضافه کند؛ به همین دلیل حالت خواب عمیق برای خاموشی قطعی ارائه شده است.

## ساخت پروژه

```powershell
dotnet publish src/TrueSleep/TrueSleep.csproj -c Release -r win-x64 --self-contained true
```
